# 09: 形态互转、活塞迁移与破坏掉落

**What to build:** 玩家能用工具把压缩泥土变成压缩草地、再变成压缩耕地（以及反向），货仓里的东西一样不少。活塞推动压缩方块时货仓内容跟着走。拆掉压缩方块时，货仓里攒的产出全部掉出来给玩家。

这三件事共用同一套「搬运 27 格数据」的代码，写两遍必然会分叉。

**Blocked by:** 03（方块与货仓）、08（GUI 与货仓读写已稳定）

**Status:** ready-for-agent

## 验收标准

### 形态互转（ADR-0002）

- [ ] 压缩泥土 ↔ 压缩草地 ↔ 压缩耕地 三种形态互转
- [ ] 互转时货仓**全部 27 格数据原样带到新方块**，包括 `chestCount`
- [ ] 互转不动等级 `L`
- [ ] 锄头右键压缩泥土 → 压缩耕地：**必须显式实现**，不能依赖原版 `HoeItem`（`TILLABLES` 是硬编码方块表、不读标签，已验证）
- [ ] 其余两种转换的触发方式在实现时确定并写进票内

### 活塞迁移（ADR-0002）

- [ ] 压缩方块能被活塞推动
- [ ] 推动后货仓内容完整保留
- [ ] 与形态互转**共用同一套 BE 搬运代码**，不复制第二份

### 破坏掉落

- [ ] 破坏压缩方块时，货仓里的全部内容作为掉落物给玩家
- [ ] 不会因为拆地而损失产出

### 不做的事

- [ ] 不按目标形态过滤货仓内容。如果需要「压缩草地上不该有作物产物」这类限制，用配方或交互解决，**不清空货仓**（ADR-0002）

## 备注

- 搬运代码的接口应该长这样：给定源 BE 和目标 BE（或目标方块），把 27 格 + `chestCount` 搬过去，然后两端都 `setChanged()`
- 破坏掉落与 08 的「破坏前重试一次结算」是两件事，都在破坏路径上但顺序不同：先重试结算（可能写入新产出），再掉出货仓内容

## Comments

2026-10-31 · 预检补充（ADR-0018）

- 草蔓延：原版 `SpreadingSnowyDirtBlock.randomTick` 只认 `is(Blocks.DIRT)`（身份比较），**不会**蔓延到压缩泥土；压缩方块之间的草蔓延由本票在 `randomTick` 里自己实现
- 水合：`CompressedFarmlandBlock` 已带 `BlockStateProperties.MOISTURE`（默认 0），本票负责按 4 格内水源/降雨把 MOISTURE 提到 7，并把 `getGrowthSpeed` 的 3.0 倍率真正用起来
- 僵尸踩踏 / 水流：压缩耕地不继承 `FarmBlock`，默认不会发生；若要等价行为，本票自己实现，且**不得**把方块替换成原版泥土（会丢货仓）
- 锄头：`HoeItem.TILLABLES` 硬编码，压缩泥土 → 压缩耕地必须由本票显式挂右键处理

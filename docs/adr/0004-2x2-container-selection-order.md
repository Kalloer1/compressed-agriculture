# 0004 · 2×2 巨树的容器选择与生长判定共用同一顺序

- 状态：已采纳（2026-10-31）
- 影响面：§6.2 基底探测、§6.3 产物获取

## 背景

方案 v1.9.2 §6.2 第 5 条给了两个并列写法，用「或」连接、未做选择：

> 从西北角 BE 开始，按西北 → 东北 → 西南 → 东南（或保持原方案的锚点 → 东 → 南 → 东南）选择第一个 BE。

## 决策

采用 **西北 → 东北 → 西南 → 东南**。

## 理由

§6.2 第 2、4 条已经确定：原版 `SaplingBlock` 的 2×2 生长基底检查**只看西北角**树苗下方那一格。既然生长判定锚定西北，容器选择也锚定西北，两个步骤用同一个顺序，才不会出现「判定依据西北格、产物写进东南格」的错位。

「锚点 → 东 → 南 → 东南」是另一套遍历序。它和生长判定无关，混用会引入一个只在「四格下方压缩方块不齐全」时才暴露的 bug，而那正是最难复现的情形。

## 后果

- 四格下方都是压缩方块时，产物固定进西北角那个 BE，规则可预测。
- 四格下方只有部分压缩方块时，按西北优先取第一个存在的 BE；一个都没有则不走压缩路径。
- 容器选择不要求四格等级一致（沿用文档原文）。
- 货仓满时的失败反馈位置 = 选中的那个 BE 上方。

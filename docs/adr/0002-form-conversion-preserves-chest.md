# 0002 · 形态转换保留货仓内容

- 状态：已采纳（2026-10-31）
- 影响面：§11.14 形态转换、§11.13 活塞 BE 迁移

## 背景

方案 v1.9.2 §2 规定 27 个 Block（3 形态 × 9 等级），BE 只存货仓、不存形态。§11 任务清单里有「草蔓延 / 水合 / 形态转换」和「活塞 BE 迁移」，但文档从未规定：形态转换时货仓里的东西怎么处理。

## 决策

形态转换时，货仓内容原样带到新方块。

## 理由

- 玩家已经通过 `9^L` 的倍率积累了货仓内容，转换是常规操作（压缩泥土 → 压缩耕地是种地的必经步骤）。清空等于每次种地都丢一次货。
- 「按目标形态过滤」需要一张「哪些物品属于哪种形态」的表，这与 §0 核心原则（不出现具体物品/方块 ID 列表）直接冲突，且无法对模组物品给出有意义的规则。
- 要求「货仓为空才能转换」会让玩家每轮都手动清仓，把自动化的收益吃掉。

## 后果

- 形态转换需搬运 BE 的全部 27 格数据，包括 `chestCount`。
- 活塞迁移（§11.13）与形态转换必须共用同一套 BE 搬运代码，避免两条路径的复制逻辑分叉。
- 若某个形态在语义上确实不该携带某类物品（例如压缩耕地储存作物产物是否合理），那是**玩法设计**问题，通过配方或交互限制解决，不通过清空货仓解决。

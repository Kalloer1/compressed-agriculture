# 手工验收清单（headless 环境验不了的部分）

装 `build/libs/compressedagriculture-1.0.0.jar` 进游戏，逐条打勾。

## 方块与合成
- [ ] 创造模式「压缩农业」标签页里有 18 个方块
- [ ] 9 泥土 → L1 压缩泥土（工作台）
- [ ] 9 个 L1 压缩泥土 → L2 压缩泥土
- [ ] 挖掉压缩方块再放回：货仓内容还在（03b）
- [ ] 创造模式中栏取的方块是干净的（空货仓）

## 种植与生长
- [ ] 压缩耕地上能种小麦/胡萝卜/马铃薯/甜菜
- [ ] 未浇水时生长速度与普通耕地一致
- [ ] 放水源后 `MOISTURE` 变 7，生长变快
- [ ] 压缩耕地上能种瓜种，茎长到 AGE=7
- [ ] 普通耕地上种瓜行为不受影响（Mixin 不误伤）
- [ ] 压缩泥土/压缩耕地上能种树苗
- [ ] 压缩耕地上能种下界疣、蘑菇（白天也不弹）、甘蔗（**不需要水**）、仙人掌、竹子
- [ ] 压缩耕地上黑暗处也能种小麦（通用地基的已知副作用）

## 收获
- [ ] 小麦长熟 → 自动进货仓，幼苗回到 0 龄，数量 = 掉落 × 9^L
- [ ] 骨粉催熟的作物也被收（延迟 1 tick）
- [ ] 骨粉催到一半（未成熟）不会被误收
- [ ] 树长成 → 整棵拆掉、掉落进货仓、原地回填树苗
- [ ] 2×2 巨树：四格都回填树苗
- [ ] 瓜：茎长熟 → 果实进货仓、茎退回 0 龄、果实不落地
- [ ] 空手右键瓜 → 手动收进货仓
- [ ] 蘑菇骨粉 → 蘑菇树整棵拆掉、回填一个蘑菇
- [ ] 手动挖蘑菇 → 进货仓、不落地
- [ ] 甘蔗 / 仙人掌 / 竹子在压缩耕地上**永远只有 1 格**，长到第 2 格自动进货仓、第 1 格还在
- [ ] 手动往压缩耕地上堆第 2 格甘蔗 → 那格被立刻收走
- [ ] 普通沙子上的甘蔗不受影响（能堆到 3 格）
- [ ] 货仓塞满后长第 2 格 → **停摆**（不拆、不丢物品）；腾空后恢复
- [ ] 下界疣长到 3 龄 → 自动进货仓、回到 0 龄

## 货仓与界面
- [ ] `chestCount = 0` 时右键打不开界面
- [ ] 扩容一次后能打开，显示 27 格 + 等级 + 容量
- [ ] 能取出物品到背包；shift 点击不会卡死
- [ ] 计数超过 9999 时显示短格式（1.2k / 3.4M）
- [ ] 扩容配方：1 压缩方块 + 8 铁锭 → 容量 +1，内容不丢

## 失败与重试
- [ ] 货仓填满 → 作物保持成熟态（不重置）
- [ ] 打开界面取走一些 → 关闭界面 → 作物被补收、重置幼苗
- [ ] 右键该方块 → 同样补收
- [ ] 拆掉该方块前 → 先补收，再掉出带数据的物品

## 形态与活塞
- [ ] 锄头右键压缩泥土 → 压缩耕地，货仓不丢
- [ ] 铲子右键压缩耕地 → 压缩泥土，货仓不丢
- [ ] 实体踩踏压缩耕地 → 变同等级压缩泥土，货仓不丢（潜行不踩）
- [ ] 活塞推动压缩方块 → 货仓跟着走
- [ ] 粘性活塞拉回 → 货仓跟着回来
